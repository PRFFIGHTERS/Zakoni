# ПРАВОСФЕРА

## Быстрый запуск

1. Установите Node.js 20+.
2. `npm install`
3. Скопируйте `.env.example` в `.env`. При желании укажите `GEMINI_API_KEY`.
4. `npm start`
5. Откройте `http://localhost:3000`

Без ключа Gemini интерфейс и локальный поиск работают. ИИ-объяснения вернут понятное сообщение о том, что сервис не настроен.

## Импорт официального файла

Автоматический публичный API pravo.gov.ru для прямого получения кодов не предоставлен. Используйте официально полученный файл (XML → преобразованный в JSON, либо официальную JSON-выгрузку) и выполните:

```bash
node importer/import.js ./official-uk.json \
  --source-url="https://pravo.gov.ru/..." \
  --sha256="<ожидаемый_хеш>" \
  --retrieved-at="2026-10-25"
